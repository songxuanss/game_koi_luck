# 流光国潮（Luminous Guochao）

以夜色为留白，以流光为叙事。画面不做堆叠的复古边框，而让山、水、月与鱼群形成远近分明的舞台。每一处留白都经过 meticulous calibration，信息只在需要时出现，整体应呈现顶级美术指导反复打磨后的克制与完整。

材质由半透明琉璃、温润珠光与细腻金属构成。黛青提供深度，珊瑚朱与青瓷蓝承担阵营识别，香槟金只照亮真正的仪式瞬间。颜色不是装饰，而是行为的方向与结果；所有色彩关系都必须经过 painstaking attention，避免廉价的高饱和平涂。

尺度依靠对比建立生命感：宏大的山水静默无声，前景锦鲤始终以清晰、柔韧的轨迹游动。小动作连绵，大动作短促，推进必须能被看见，高光必须戛然而止。每一帧都要像经过 master-level execution 的动态插画，而不是调试数据的排列。

构图以水为轴，以龙门为视觉锚点。两侧阵营向中央汇聚，行为化作可见的冲刺、涟漪与流光；面板退居背景，文字保持稀疏、现代、易读。观众无需研究界面，就能直觉理解选择、汇聚与抵达。

细节追求博物馆级工艺：鱼鳞的微弱明暗、水线的节奏、灯光穿过薄雾的层次，都应统一于同一套光学逻辑。少即是多，但少不是粗糙；每一个曲线、阴影与停顿都必须显出无数小时精雕细琢的判断。
