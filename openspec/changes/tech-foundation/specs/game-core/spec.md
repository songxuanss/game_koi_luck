# Spec Delta: game-core

## Purpose

玩法对局核心：纯 TS 实现的房间状态机与对局逻辑（阶段循环/助力值经济/胜负判定/阵营平衡），平台无关、数值全配置化，是整个玩法的确定性结算中枢。

## ADDED Requirements

### Requirement: 房间状态机与三阶段循环

系统 SHALL 以房间为单位管理对局，单局 MUST 按三阶段推进：蓄势（免费参与为主）→ 攻防竞速（付费主阶段）→ 鸿运时刻（效果加倍收尾），随后进入结算期。各阶段时长 MUST 由服务端配置驱动，可按在线人数弹性伸缩。

#### Scenario: 标准对局推进
- **WHEN** 房间创建并开局，无人工干预
- **THEN** 对局按配置时长依次经历三阶段并自动进入结算，全程事件驱动状态转换

#### Scenario: 空场弹性
- **WHEN** 房间在线参与人数低于配置阈值
- **THEN** 蓄势阶段按配置缩短，对局仍能完整走完三阶段

### Requirement: 助力值经济与档位映射

系统 SHALL 以助力值为唯一对外计量单位（贡献/榜单/归因）；礼物事件 MUST 按其价值档位（T0~T7）映射为助力值与进度（映射表服务端配置）。助力值与进度 MUST 分离：T5 及以上档位的进度贡献受配置上限约束，单件礼物进度 MUST NOT 超过胜负线的 12.5%（方案 5.9 ⑧）。系统 MUST NOT 在任何对局数据结构中存储或输出金额信息。

#### Scenario: 档位礼物结算
- **WHEN** 一条 gift 事件携带 T4 档位标记
- **THEN** 对局按配置表为该用户所在阵营增加对应助力值，并生成该档位的单位/效果

#### Scenario: 大额不独立决胜
- **WHEN** 一条 gift 事件携带 T7 档位标记
- **THEN** 该用户助力值按 T7 计入贡献榜，但阵营进度增加不超过胜负线的 12.5%

#### Scenario: 随机外观款专属
- **WHEN** 一条 T4 价值区间的 gift 事件未被标记为指定随机外观款
- **THEN** 按配置的降级档位（默认 T3）生成效果，不召唤精英锦鲤、不做皮肤随机

#### Scenario: 金额零泄漏
- **WHEN** 检查 game-core 对外输出的一切对局状态与事件
- **THEN** 不存在以货币单位（元/分/抖币等）表述的数值字段

### Requirement: 进度条胜负判定

系统 SHALL 以进度条为唯一胜负判定：任一阵营进度先达 100%（配置的助力值当量）即获胜；攻防动作 MUST 仅产生两类效果——加速己方或拖慢对方，MUST NOT 存在第二胜负条件。

#### Scenario: 单一胜负条件
- **WHEN** 领先方进度率先达到 100%
- **THEN** 对局立即进入结算，胜方为该阵营，无其他判定路径

#### Scenario: 计时耗尽（终局潮汐）
- **WHEN** 鸿运时刻结束时双方进度均未达 100%
- **THEN** 进入终局潮汐：双方按配置速率等速自动推进（互动照常计入），先达 100% 者胜；同帧越线时进度高者胜，完全相等记平局

### Requirement: 阵营自动平衡

系统 SHALL 实时计算阵营平衡因子：人数失衡时人少方产出按公示公式加权（`w = clamp((N多/N少)^0.4, 1.0, 1.35)`）；进度差 ≥20% 时落后方产出再乘 1.25，差回落至 <10% 移除。平衡规则 MUST 在规则说明中公示。

#### Scenario: 人数虹吸补偿
- **WHEN** 双方入场人数比达到 7:3
- **THEN** 人少方全部产出按公式加权，加权系数在公示区间内

### Requirement: 数值全配置化

系统 MUST NOT 硬编码任何对局数值（助力值表/阶段时长/平衡参数/单位属性）；全部数值 MUST 来自服务端配置并支持热更新。

#### Scenario: 数值调优不发版
- **WHEN** 运营在配置中心调整某档位助力值并热更新
- **THEN** 下一局起按新数值结算，进行中的对局按策略（配置项）决定是否生效

### Requirement: 平台无关性

game-core MUST NOT import 任何平台 SDK、不得出现平台专属类型；其输入 MUST 仅为 LiveEvent、时钟推进（tick）与控制指令（开局），且全部携带显式时间戳；输出 MUST 为对局状态快照与效果指令。内核 MUST NOT 读取实时钟或非确定性随机源（随机外观使用以事件幂等键为种子的确定性 PRNG）。

#### Scenario: 架构依赖审查
- **WHEN** 对 game-core 模块执行依赖扫描
- **THEN** 不存在任何平台适配器或平台 SDK 的引用
